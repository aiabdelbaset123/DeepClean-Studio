============================================================
  DeepClean Studio — Run Instructions (Lightweight Edition)
============================================================

1. PREREQUISITES
   - Python 3.8+ (3.10+ recommended)
   - pip package manager
   - NO heavy ML models needed! The app uses rule-based NLP only.

2. INSTALLATION
   Open a terminal in the project directory and run:

     pip install streamlit

   That's it! Only ONE package is required.

   Optional (for file upload support):
     pip install python-docx pdfplumber

3. PREPARE SYNONYM DATABASE
   Ensure "synonyms_academic.csv" is in the SAME directory as app.py.
   If missing, the app will auto-create a built-in fallback database.

4. LAUNCH THE APP
     streamlit run app.py

   The app opens in your browser at http://localhost:8501

5. USAGE
   a) Upload a .txt / .docx / .pdf file OR paste text directly.
   b) Adjust "Transformation Strength" (1=conservative, 5=aggressive).
   c) Select "Academic Field" (General / Medical / Engineering / Humanities).
   d) Click "🛡️ Initiate Secure Humanization".
   e) Review the humanized output in the right column.
   f) Check local metrics (Perplexity Proxy, Burstiness, TTR) in sidebar.
   g) Optionally enable "Show changes for human review".
   h) Download the result via the ⬇️ button.

6. WHAT'S DIFFERENT IN THIS LIGHTWEIGHT EDITION
   - NO GPT-2 (saves ~524 MB download + long loading time)
   - NO SentenceTransformer (saves ~90 MB)
   - NO spaCy (saves ~40 MB)
   - NO nltk (saves ~15 MB)
   - NO PyTorch (saves ~2 GB)
   - Uses a pre-built AI-favored words table for perplexity proxy
   - Uses Jaccard + content-word overlap for similarity checking
   - Uses a built-in sentence tokenizer (handles academic abbreviations)
   - Total installation: ~15 MB (just Streamlit) vs ~3 GB before
   - Startup time: ~3 seconds vs ~2-5 minutes before

7. IMPORTANT NOTES
   - All processing runs locally; no text is sent to external APIs.
   - The "Local Self-Check Metrics" are estimates only.
   - For best results, use strength 3-4 for academic text.

8. TROUBLESHOOTING
   - "ModuleNotFoundError: No module named 'streamlit'":
     Run: pip install streamlit
   - Blank page / slow loading:
     This edition should load instantly. If not, check your internet
     connection (Streamlit may try to load CSS resources).
   - CSV not found:
     The app creates a built-in fallback automatically.

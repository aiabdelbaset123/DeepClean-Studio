============================================================
  DeepClean Studio — Run Instructions
============================================================

1. PREREQUISITES
   - Python 3.10+ (3.11 recommended)
   - pip package manager
   - ~4 GB disk space (for GPT-2 + SentenceTransformer models)

2. INSTALLATION
   Open a terminal in the project directory and run:

     pip install -r requirements.txt
     python -m spacy download en_core_web_sm

   The first run will also download:
     - GPT-2 small (~524 MB)
     - all-MiniLM-L6-v2 (~90 MB)
     These are cached automatically by Hugging Face / SentenceTransformers.

3. PREPARE SYNONYM DATABASE
   Ensure "synonyms_academic.csv" is in the SAME directory as app.py.
   The CSV must have columns: word, field, synonym, specificity_boost

4. LAUNCH THE APP
     streamlit run app.py

   The app opens in your browser at http://localhost:8501

5. USAGE
   a) Upload a .txt / .docx / .pdf file OR paste text directly.
   b) Adjust "Transformation Strength" (1=conservative, 5=aggressive).
   c) Select "Academic Field" (General / Medical / Engineering / Humanities).
   d) Click "🛡️ Initiate Secure Humanization".
   e) Review the humanized output in the right column.
   f) Check local metrics (Perplexity, Burstiness, TTR) in the sidebar.
   g) Optionally enable "Show changes for human review" to inspect each
      modification and accept/reject individual changes.
   h) Download the result via the ⬇️ button.

6. IMPORTANT NOTES
   - First run is slow due to model downloads; subsequent runs are faster.
   - For long documents (>5,000 words), processing may take several minutes.
   - The "Local Self-Check Metrics" are estimates only — they do NOT
     guarantee bypassing any external AI detector.
   - All processing runs locally; no text is sent to external APIs.

7. TROUBLESHOOTING
   - "ModuleNotFoundError": Run pip install -r requirements.txt again.
   - CUDA out of memory: Set CUDA_VISIBLE_DEVICES="" to force CPU mode,
     or reduce input length.
   - Slow startup: GPT-2 and SentenceTransformer download once;
     subsequent starts are ~10-15 seconds.

============================================================
  DeepClean Studio v3.0 — Run Instructions
============================================================

1. INSTALLATION (only 2 packages!)
     pip install streamlit python-docx

   Optional (for PDF upload support):
     pip install pdfplumber

2. LAUNCH
     streamlit run app.py

   Opens at: http://localhost:8501

3. USAGE
   a) Upload a .docx file (RECOMMENDED — preserves all formatting:
      equations, figures, tables, references, citations, images)
      OR upload .txt/.pdf, OR paste text directly.
   b) Set "Transformation Strength" (1=conservative, 5=aggressive).
   c) Select "Academic Field".
   d) Click "🛡️ Initiate Secure Humanization".
   e) Download result as:
      - DOCX (formatted, preserves all original formatting)
      - TXT (plain text)
      - PDF (if LibreOffice is installed)

4. KEY FEATURES v3.0
   - ✅ DOCX output with FULL formatting preservation
   - ✅ Equations, figures, images, tables preserved
   - ✅ Citations and references untouched
   - ✅ AI vocabulary removal (based on Wikipedia research)
   - ✅ Superficial analysis phrase removal
   - ✅ "Serves as / boasts / features" → simple "is / has"
   - ✅ 5-module humanization engine
   - ✅ AI Vocabulary Density metric (new!)

5. TROUBLESHOOTING
   - "ModuleNotFoundError": pip install python-docx streamlit
   - DOCX equations/images missing: ensure the uploaded .docx
     actually contains them; the app preserves them automatically.
   - PDF conversion unavailable: install LibreOffice for PDF export.
